# organizador-tarefas-estudantes
Sistema web para organização de tarefas acadêmicas


## Problema e solução
Problema: Muitos estudantes têm dificuldade para organizar suas tarefas acadêmicas, lembrar os prazos de entrega e definir quais atividades precisam ser feitas primeiro. Isso pode causar atrasos, acúmulo de trabalhos e falta de organização na rotina de estudos.

Solução: O projeto **Organizador de Tarefas para Estudantes** foi desenvolvido para ajudar os alunos a gerenciar suas atividades de forma simples e prática. O sistema permite cadastrar tarefas, informar a matéria e a data de entrega, definir prioridades, acompanhar atividades pendentes ou atrasadas e marcar tarefas como concluídas. Além disso, os dados ficam salvos no navegador, permitindo que o estudante consulte suas tarefas mesmo depois de fechar a página.

## Tecnologias utilizadas
HTML, JavaScript e CSS


## Como instalar e executar
Acesse o repositório do projeto no GitHub.

Baixe os arquivos do projeto ou clique em Code → Download ZIP.

Extraia os arquivos para uma pasta no computador.

Verifique se os arquivos index.html, style.css e script.js estão na mesma pasta.

Abra o arquivo index.html em um navegador, como Google Chrome ou Microsoft Edge.

## Funcionalidades implementadas
Cadastro de tarefas: permite adicionar novas atividades acadêmicas.

Organização por disciplina: possibilita informar a matéria relacionada a cada tarefa.

Definição de prazos: permite estabelecer uma data de entrega.

Níveis de prioridade: classifica as tarefas como alta, média ou baixa prioridade.

Controle de conclusão: permite marcar tarefas como concluídas ou pendentes.

Identificação de atrasos: destaca tarefas cujo prazo já passou e que ainda não foram concluídas.

Filtros de tarefas: permite visualizar todas as tarefas, somente as pendentes ou somente as concluídas.

Filtro por disciplina: facilita localizar atividades de uma matéria específica.

Contadores de atividades: mostra o total de tarefas, as pendentes e as atrasadas.

Exclusão de tarefas: permite remover atividades cadastradas.

Tema claro e escuro: oferece suporte à alternância entre os temas.

Armazenamento local: salva as tarefas no navegador utilizado, mantendo os dados disponíveis após fechar e abrir a página novamente.
